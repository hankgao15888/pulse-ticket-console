# PULSE 本机定时填表代理

在“添加场次”中录入官方链接、北京时间（支持秒）、个人资料及票数；本机程序识别表单后，由你确认各项资料对应的官方字段，再预约填写。

**当前功能是定时填表，并非全自动抢票服务。没有接入实时票源，不会自动选择大麦场次/票档、自动提交订单或付款，也不保证能进入购票页。**

## 启动（Windows）

1. 安装 Node.js 22 或更高版本，并确认已安装 Microsoft Edge。
2. 解压完整项目，双击 start.cmd。首次会安装 Playwright 依赖，不需要另行下载浏览器。
3. 打开 http://127.0.0.1:4180 。不要直接双击 index.html。
4. 点击“本机演练”可以使用虚构资料体验整个流程。

也可在本目录执行 npm ci，然后执行 npm start。

## 使用你的大麦链接

控制台提供“添加这场大麦”按钮，预填官方链接 https://detail.damai.cn/item.htm?id=1092331547013 。名称来自提供的链接，实际演出信息与开售时间需在官方页面核对。

1. 添加场次 → 填链接、时间、个人资料 → 勾选“保存为本机代理任务”。个人资料至少填一项。
2. 在代理面板点击“打开页面 / 重新识别”。程序打开独立 Edge。请在这个窗口手动登录、完成验证，并选择场次和票档。
3. 进入真正的填写页面后，回控制台点击“重新识别”。仅识别当前页面可见、可编辑的文本/数字/下拉字段；不识别原生 App、小程序、跨域 iframe 或不可访问的页面。
4. 若订单页跳到同一平台的其他域名，先核对并授权该域名。资料不会自动发送到未经确认的域名。
5. 确认每项资料对应的字段，点击“确认字段并预约”。所有项目必须对应不同的目标字段，否则不执行。
6. 到时自动填写一次。请在官方页面核对票档、数量与金额，手动提交订单和付款。

**已实际核验当前大麦详情页：顶部搜索框会被排除，页面当前没有进入实名购票表单。通常需要先登录、选择场次和票档；若仍识别不到字段，程序只会提示接管，不会伪装为抢票成功。**

## 后台与资料

- 可关闭控制台网页，但代理程序与专用购票浏览器必须保持运行；电脑不能关机或休眠。
- 任务检查间隔 250 毫秒，以电脑时钟为准，不保证网络或平台响应速度。延迟超过一分钟会停止执行。
- 姓名、手机号和证件号只保存在代理进程内存。保存后清空输入框，不进入 localStorage、备份、GitHub、日志或任务状态接口。
- 取消、失败或填写结束后清除代理中的资料；已填入官方浏览器的内容仍留在官方页面。
- 退出/重启代理会丢失任务和登录会话，请重新录入并预约。当前不保存任何账号密码，也不提供云端托管。
- 本机服务仅监听 127.0.0.1:4180，不接受远程网站的控制请求；网页版需要打开本机控制台才能录入资料。

## 验证

npm test：任务时序、重复执行、取消、跳转/验证阻断、敏感资料隔离、本机接口权限测试。

本机代理运行时，执行 node --test browser-demo.test.mjs 测试虚构资料的实际 Edge 填写；执行 node --test browser-ui.test.mjs 测试界面保存和移动端布局。这些测试不会访问真实票务平台或购买门票。

## GitHub Pages

仓库仍可通过 main 分支根目录发布静态网页版。Node 后台只能在本机或自行管理的服务器运行，GitHub Pages 不运行 server.mjs。请勿把真实资料、账号会话或日志提交到仓库。
