# PULSE 抢票作战台

个人票务准备网站，支持火车票、演唱会、展览和赛事。

- 北京时间开售倒计时与场次管理
- 开售前 60、10、1 分钟页面提醒
- 独立的准备清单、官方入口与自定义链接
- 本地保存、JSON 备份导入导出

本项目不接入实时票源；回流时间窗仅供人工查看参考。提醒要求页面保持打开，后台休眠可能导致提醒延迟。网站不会自动下单。

## 本地预览

使用任意静态 HTTP 服务器打开本目录，例如安装 Node.js 后运行 npx --yes http-server .。系统通知需要浏览器授权。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支与 / (root) 目录，保存后等待部署完成。

## 隐私

场次数据和检查项保存在当前浏览器的 localStorage 中，不包含账号密码，也不会随源码上传。清除浏览器数据前请导出备份。
